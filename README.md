## Описание проекта
**SignalGenerator** - это приложение для генерации, анализа и визуализации сигналов с широкими возможностями постобработки. 

Проект предоставляет удобный интерфейс для создания различных типов сигналов, применения фильтров и трансформаций, вычисления статистик и сохранения результатов. 

Приложение поддерживает работу с вещественными, комплексными и двумерными сигналами, обеспечивая высокую производительность за счет оптимизированных математических операций и эффективной отрисовки данных.

## Архитектура решения
Проект построен по модульной архитектуре с четким разделением ответственностей:

* **SignalCore** - ядро приложения, содержащее всю бизнес-логику:
  * **signals** - реализация генераторов, фильтров, трансформаций, нормализаций и статистик сигналов
  * **computation** - система ленивых вычислений с отслеживанием прогресса и возможностью отмены
  * **storage** - слой хранения данных с использованием SQLite и системы сериализации ObjectFactory
  * **gui_state** - управление состоянием GUI независимо от представления
  * **utils** - вспомогательные утилиты и расширения

* **SignalGUI** - графический интерфейс пользователя на базе AvaloniaUI, обеспечивающий кроссплатформенность

* **SignalTests** - модульные и интеграционные тесты для проверки корректности работы бизнес-логики

Архитектура позволяет легко расширять функциональность за счет использования интерфейсов и системы ObjectFactory для сериализации/десериализации объектов.

### Архитектурные принципы
Архитектура проекта в целом следует принципам SOLID, обеспечивая модульность, тестируемость и расширяемость. Однако, в некоторых классах, таких как `GuiStateConverter` и `SignalStorage`, имеются нарушения принципов, требующие дальнейшей работы по рефакторингу для повышения качества кода и поддерживаемости.

## Установка и запуск
Для запуска проекта установите .NET SDK 10, клонируйте репозиторий и выполните следующие команды:

```
git clone https://github.com/Kemsekov/DotnetSignalGenerator
cd DotnetSignalGenerator/SignalGUI && dotnet run
```

Проект разработан с использованием AvaloniaUI, что обеспечивает кроссплатформенную совместимость с Linux, Windows и macOS. Приложение протестировано в основном на Linux, но должно корректно работать и на других платформах.

## Высокая скорость обработки данных
Все математические операции реализованы с использованием NumpyDotnet - высокопроизводительной библиотеки для численных вычислений. Это обеспечивает быструю обработку сигналов даже при работе с большими объемами данных, позволяя выполнять сложные фильтрации, трансформации и статистический анализ в реальном времени.


## Сохранение и загрузка сессий
Приложение поддерживает полное сохранение и восстановление состояний сессий, включая все параметры генерации сигналов, примененные фильтры, трансформации, нормализации и статистики. Все данные сохраняются в локальную SQLite базу данных, что позволяет продолжать работу с ранее созданными сигналами и экспериментами в последующих сессиях.


## Высокая эффективность отрисовки больших данных
Для визуализации сигналов применяется оптимизированная интерполяция библиотеки NumPy, обеспечивающая одинаково высокую производительность при отображении как малого, так и большого количества точек данных. Это позволяет эффективно визуализировать сигналы с миллионами точек без потери отзывчивости интерфейса.


## Неблокирующая генерация сигналов
Все операции генерации сигналов реализованы в асинхронном, неблокирующем режиме с поддержкой отложенных вычислений. Пользователь может отслеживать прогресс выполнения и отменять длительные операции в любое время. Система основана на классе `TrackedOperation` из файла `SignalCore/computation/Lazy.cs`, который обеспечивает контроль выполнения и возможность отмены даже для цепочек сложных операций.


## Поддержка фильтров, трансформаций, нормализации и подсчёта статистики сигналов
Приложение предоставляет богатый набор инструментов для обработки и анализа сигналов.

### Фильтры
* **LowPassFilter**: Фильтр нижних частот для сглаживания сигналов и подавления высокочастотного шума.
* **HighPassFilter**: Фильтр верхних частот для удаления медленных изменений и постоянной составляющей.
* **AddNormalNoiseFilter**: Добавляет нормальный шум с заданными параметрами.
* **CutOutliersFilter**: Удаляет выбросы, ограничивая значения заданными квантилями.
* **BilateralFilter**: Нелинейный фильтр, сглаживающий сигналы с сохранением границ.


### Трансформации
* **FFTTransform**: Преобразование Фурье для анализа частотного спектра сигнала.
* **InverseFFTTransform**: Обратное преобразование Фурье из частотной области во временную.
* **FWTTransform**: Вейвлет-преобразование для многоразмерного анализа сигналов.
* **InverseFWTTransform**: Обратное вейвлет-преобразование для восстановления сигнала.


### Нормализация
* **MinMaxNormalization**: Нормализует сигнал к заданному интервалу, масштабируя значения к указанному диапазону.
* **ZScoreNormalization**: Нормализует сигнал к заданному среднему значению и стандартному отклонению, преобразуя данные в z-оценки.


### Статистика
Полная поддержка статистического анализа сигналов:
* Mean (среднее), STD (стандартное отклонение)
* 0.25 и 0.75 квантили
* RMS (среднеквадратичное значение)
* Amplitude (амплитуда)
* Crest Factor (коэффициент формы)
* Median (медиана)
* Minimum (минимум), Maximum (максимум)
* Skewness (асимметрия), Kurtosis (эксцесс) 
* Energy (энергия), Power (мощность)


## Комплексное тестирование бизнес-логики
Проект включает 96 модульных и интеграционных тестов в проекте `SignalTests`, охватывающих большую часть бизнес-логики приложения.

Тесты проверяют ключевые компоненты системы: **генерацию сигналов различных типов**, **операции с сигналами** (фильтры, трансформации, нормализации), **систему ленивых вычислений** с отслеживанием прогресса и возможностью отмены, **сериализацию и десериализацию объектов** через ObjectFactory, **сохранение и загрузку состояний** GUI, а также вспомогательные утилиты (например, CastOrThrow).

Это гарантирует надежность и точность всех вычислений и основных функций приложения.


## Простота расширения функционала и обработка исключений
Приложение реализует продуманную систему обработки исключений с визуализацией ошибок, позволяющую интегрировать проверку параметров генерации и фильтрации прямо в бизнес-логику, минуя интерфейсную часть.

Архитектура приложения использует механизмы рефлексии, что позволяет легко расширять функционал без необходимости изменять код пользовательского интерфейса.

Интерфейс автоматически сканирует пространства имен приложения и обнаруживает все реализации ключевых интерфейсов генерации, обработки сигналов, нормализаций и статистик, обеспечивая гибкость и расширяемость системы.


## Генерация сигналов различных типов
Приложение поддерживает одновременную генерацию сигналов различных типов с настраиваемыми параметрами амплитуды, смещений, времени начала и окончания генерации, а также фазы:
* **Sinusoid**: Синусоидальный сигнал с возможностью настройки частоты, амплитуды и фазы
* **Square**: Прямоугольный (меандр) сигнал с регулируемыми параметрами
* **Triangle**: Треугольный сигнал с линейным изменением амплитуды
* **SawTooth**: Пилообразный сигнал с линейным нарастанием и резким спадом

### Возможность объединения сигналов
Для комбинирования сигналов используется система математических выражений: каждому сгенерированному сигналу присваивается буквенное обозначение, и с помощью этих обозначений можно создавать сложные комбинации сигналов с помощью математических операций (сложение, вычитание, умножение и т.д.), в том числе, с поддержкой мат-функций через объект `np`

## Поддержка визуализации различных типов сигналов
Приложение обеспечивает полноценную визуализацию различных типов сигналов:
* **Вещественные сигналы** - отображаются в виде традиционных графиков
* **Комплексные сигналы** - визуализируются с отображением как вещественной, так и мнимой частей, включая результаты FFT-преобразований
* **Двумерные данные** - поддерживаются для визуализации результатов вейвлет-преобразований (FWT) и других многомерных представлений сигналов
